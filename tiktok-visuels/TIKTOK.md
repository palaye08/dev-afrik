## 4. Les règles pour rendre tes posts viraux

1. **La 1re image / 1re seconde décide de tout** : une promesse claire ou une erreur que les gens font.
2. **Un seul sujet par post.** Simple et concret.
3. **Termine par une question** → les commentaires boostent la portée. Réponds à TOUS les commentaires la 1re heure.
4. **Demande d'enregistrer** (« garde ce post ») : les enregistrements comptent beaucoup.
5. **Publie tous les jours**, à heure fixe. Heures à tester au Sénégal : **12 h–14 h** et **19 h–22 h**.
6. **Mélange les formats** : carrousels photo (faciles), vidéos face caméra de 20–40 s, écran de code filmé.
7. **Recycle ce qui marche** : si un post décolle, refais-le sous un autre angle la semaine suivante.
8. **Ne vends pas dans chaque post** : 4 posts utiles pour 1 post qui présente un produit.
